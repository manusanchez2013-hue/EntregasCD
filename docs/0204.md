# Ejercicios — Tema 2: Ingenieria de Software
------------------------------------
## Ejercicio 4 — Redacción de historias de usuario
____________________________________

# historias 

1. Como socio quiero devolver un libro para dar por terminado el préstamo;
2. Como bibliotecario quiero consultar  el prestamo de cierto libro para llevar control de los libros prestados y a quien.
3. Como administrador del sistema quiero hacer un recuento de libros prestados para poder reclamarlos.
# Comrobación de los INVEST

| Criterio | Socio | Bibliotecario | Administrador |
| ----------|--------|------------|-------|
Independiente  | Si, no depende de otras historias.  | Si, no depende de otras historias. | Si, no depende de otras historias. |
| Negociable  |  Si, Puedo devolverlo ahora o en un momento concreto futuro. | Si, puedo hacer consulta por libro o por socio. | Si, puedo hacer consulta por libro o por socio. |
| Valuable: | Si, Permite volver a poner el libro en prestamo. | Si, Permite saber quien tiene un libro para realizar cualquier acción. | Si, Permite saber quien tiene los libros y reclamarlos. |
| Estimable: | Si, se puede saber cuanto cuesta realizar las acciones. |  Si, se puede saber cuanto cuesta realizar las acciones. |  Si, se puede saber cuanto cuesta realizar las acciones. |
| Small: | Si, cabe en un sprint. | Si, cabe en un sprint. |Si, cabe en un sprint. | Si, cabe en un sprint. |
| Testable: | Si, se puede comprobar en un caso concreto de devolución. | Si, se puede comprobar en un caso concreto de consulta. | Si, se puede comprobar en un caso concreto de recuento. |

## Criterio 1
* Dado que el libro existe en biblioteca.
* Cuando el bibliotecario busca por titulo .
* El sistema muestra que lo tiene en stock.

## Criterio 2
* Dado que el libro  existe en biblioteca, pero está prestado.
* Cuando el usuario Busca por titulo y está prestado
* El sistema muestra que está prestado.

## Criterio 3
* Dado que el libro no existe en biblioteca.
* Cuando el usuario Busca por titulo y no existe .
* El sistema muestra que no consta y pide introducción de otro titulo.
