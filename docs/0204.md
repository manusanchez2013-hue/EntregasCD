## Ejercicio 4 — Redacción de historias de usuario
____________________________________

# historias 

1. Como socio quiero devolver un libro para dar por terminado el préstamo;
2. Como bibliotecario quiero consultar el administrador para saber quien tiene cierto libro;
3. Como administrador del sistema quiero hacer un recuento de libros prestados para poder reclamarlos;

# Comrobación de los INVEST

Independiente:

              1.Si, Puedo elegir cuando lo devuelvo, o como lo devuelvo:
              2.Si, Puedo hacer una consulta detallada o solo el nombre; 
              3.Si, Puedo hacer consulta detallada o solo cuando se debe devolver;

Negociable:  
               
              1.Si, Puedo devolverlo ahora o en un momento concreto futuro;
              2.Si, puedo hacer consulta por libro o por socio;
              3.Si, puedo hacer recuento por titulos  o por fechas de fin de préstamo;

Valuable:

              1.Si, Permite dar por finalizada la deuda;
              2.Si, Permite saber a quien reclamar el libro;
              3.Si, Permite saber que libros no se pueden prestar y reclamarlos;

## Criterio 1
* Dado que el libro existe en biblioteca.
* Cuando el bibliotecario busca por titulo .
* El administrador muestra que lo tiene en stock.

## Criterio 2
* Dado que el libro no existe en biblioteca.
* Cuando el usuario Busca por titulo y está prestado.
* El sistema muestra que está prestado.

## Criterio 3
* Dado que el libro no existe en biblioteca.
* Cuando el usuario Busca por titulo y no está en base de datos.
* El sistema muestra que no consta y pide introducción de otro titulo.
