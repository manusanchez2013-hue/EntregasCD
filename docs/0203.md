# Ejercicios — Tema 2: Ingenieria de Software
------------------------------------
## Ejercicio 3 — Ciclo de vida en la práctica
____________________________________

1- Iterativo ya que va a haber muchas actualizaciones de estado por que hay muchos cambios en los requisitos debido a esa interacción entre el equipo y el cliente

2- Ágil ya que recibe cambios de requisitos continuos y esto implica un ambiente colaborativo con mucha interacción con el cliente.

3-
____________________________________
| Clase : Envio | ------- |
| --------------| ------- |
| Responsabilidades: |Colaboradores |
| Conocer Artículos |
| Conocer estado de los artículos | Repartidor |
| Informar estado de artículos | Repartidor |
| Actualizar estado de artículos | Repartidor |

| Clase : Repartidor | ----------- |
| ------------------- | ------------ |
| Responsabilidades | Colaboradores |
| Conocer Artículos | Envio
| Actualizar estado de artículos | Envio
____________________________________

4- Que dato recibe : Estado nuevo del envio.
Valores posibles del nuevo estado : En almacen, En reparto, Entregado o Devuelto.
Cuando se pide una actualización de estado éste devolvera el valor recibido de la Actualización siempre que esté dentro de los Valores posibles, de lo contrario no cambia de estado indicando  la imposibilidad de aplicar dicho cambio .

Desde que se hace el pedido los estados pasan de 1º En Almacen, mientras no sale el pedido , 2º En reparto, una vez que sale de almacén y hasta que es entrega a cliente, 3º Entregado , una vez que el repartidor lo entrega al cliente, y en caso de que el cliente lo devuelva  podra aparecer un 4º estado de Devuelto.
