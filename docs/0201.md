# Ejercicios — Tema 2: Ingenieria de Software

## Ejercicio 1 — Diseño  con targetas CRC

1.-Tarjetas CRC: 

Clase 1: Libro;
Responsabilidades: Conocer los libros que hay en la biblioteca;
                   disminuir los libros que salen de la biblioteca;
                   aumentar los libros que entran en la biblioteca;
Colaboradores: Base de datos, sin dependencia;

Clase 2: Socio;
Responsabilidades: Conocer la existencia de socios;
                   aumetar socios cuando entran nuevos socios;
                   disminuir socios cuando se eliminan socios;
Colaboradores: Base de datos, sin dependencia;

Clase 3: Préstamo;
Respnsabilidades: Gestionar cuando entra o sale un libro y su stock;
                  si hay permitir el préstamo a un socio;
                  si no hay saber que socios lo tienen;
Colaboradores: Base de datos Libro y Base de datos Socio;
                  
2-Descripción para clase Libro al prestar un ejemplar:
comprobar en la base de datos libro su existencia;
Si existe permitir su prestamo registrando el socio que lo lleva y cuantos ejemplares quedan en stock;
Si no existe o stock =0 denegar su prestamo y dar a conocer los socios que lo tiene;

3-Describir el flujo indicando clase y colaboradores;
-La base de datos Libro debe dar de alta ese libro con la cantidad de 3 en stock;
-La base de datos Socio debe dar de alta dos socios con sus atributos nombre direccion telefono...;
-El primer socio pide prestado un libro con éxito ya que hay 3 ejemplares;
-El segundo socio pide prestado un libro con éxito ya que quedan 2 ejemplares;
-El primer socio devuelve el libro , por lo que la base de datos lo registra pasando de 1 a 2 ejemplares;
-El segundo socio vuelve a intentar tomar el libro y vuelve a tener éxito;

Teniendo en cuenta este último enunciado creo que he confundido la primera premisa "Se da de alta un libro con 3 ejemplares" partiendo de que eran 3 ejemplares del mismo libro, pues de ser distintos libros esperaría que se dieran de alta 3 libros con 1 ejemplar cada uno. como en el último supuesto el segundo socio vuelve a intentar tomar el libro deduzco que el primer intento fue fallido por lo tanto modifico la descripción.

-La base de datos Libro debe dar de alta 3 libros;
-La base de datos Socio debe dar de alta dos socios con sus atributos nombre direccion telefono...;
-El primer socio pide prestado un libro con éxito ya que hay 1 ejemplare;
-El segundo socio pide prestado un libro sin éxito ya que lo tiene el primer socio;
-El primer socio devuelve el libro , por lo que la base de datos registra la entrada;
-El segundo socio vuelve a intentar tomar el libro y tiene éxito;
