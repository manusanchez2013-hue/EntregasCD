# Ejercicios — Tema 2: Ingenieria de Software
------------------------------------
## Ejercicio 5 — Product backlog con scrum
____________________________________

1. Roles

Product owner: Luis (director)
Scrum master: Marta
Development team: todo el equipo de desarrollo

2. Historias de usuario

* Como profesor.
Quiero subir material didáctico.
Para que el alumnado pueda accedar a el.

* Como alumno.
Quiero acceder al material didáctico por temas o semanas.
Para poder descargar lo que realmente necesito.

* Como profesor.
Quiero programar exámenes. 
Para poder hacer evaluación de conocimientos. 

* Como profesor.
Quiero corregir automaticamente exámenes. 
Para poder ahorrar tiempo. 

* Como alumno.
Quiero recibir notificaciones.
Para saber cuando hay material nuevo.

3. Criterios de aceptación:

* Dado que el profesor selecciona material a subir , cuando pulsa Subir material , entonces el material queda disponible para el acceso del alumno.

* Dado que el profesor selecciona material no soportado  a subir , cuando pulsa Subir material , entonces el sistema manda un aviso de "material no soportado".

* Dado que el  alumno selecciona un tema concreto  , cuando pulsa acceder , entonces solo el material de dicho tema queda disponible para el acceso del alumno.

* Dado que el  alumno selecciona un tema concreto que todavia no se ha dado   , cuando pulsa acceder , entonces el sistema manda un aviso "El Tema aun no se ha dado ".

* Dado que el profesor selecciona formular examen de tema , cuando pulsa subir  , entonces el exámen queda disponible para su realización por el alumno. 

* Dado que el profesor selecciona formular examen de tema y el tema aun no ha sido abierto , cuando pulsa subir  , entonces el sistema devuelve advertencia "El tema no se ha dado". 

* Dado que el alumno ha realizado el  examen , cuando pulsa subir respuestas , entonces el sistema contrasta con plantilla para dar puntuación. 

* Dado que el alumno ha realizado el  examen y subido respuestas, cuando pulsa recibir nota , entonces el sistema devuelve la  puntuación. 

* Dado que el profesor selecciona material a subir , cuando pulsa Subir material , entonces el alumno recibe notificación de material nuevo.

* Dado que el sistema ha notificado nuevo material ,Cuando el alumno entra en la notificación, entonces el material se visualiza en el dispositivo del alumno.

4. Estimación con planing poker

* Subir material :8
* Acceder por Tema, Semana :3
* Programar exámenes :13
* Corrección automatica :8
* Recibir notificaciones :5

5. Product Backlog

* 1. Subir material: Imprescindible para que tengo utilidad la plataforma.
* 2. Programar exámenes: Fundamental para el equipo docente.
* 3. Corregir examenes: Existe dependencia con la historia anterior.
* 4. Acceder por tema: de facil agregación.
* 5. Recibir notificación: Facilita el uso de la plataforma para el usuario.
